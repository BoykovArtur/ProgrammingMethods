## Оговорка разработчика и условия использования

Применять только в учебных целях. Данный код может содержать ошибки, автор не несёт никакой ответственности за любые последствия использования этого кода.

### Системные требования

Данный пример разработан и проверен на ОС Windows 11 Pro; авторы предполагают, что без каких-либо изменений этот код может работать для других Windows систем. В таких случаях пользователю необходимо самостоятельно установить требуемое ПО или воспользоваться виртуальной машиной с Ubuntu (также можно использовать WSL версии не ниже 2). Для Linux (за исключением Debian-подобных дистрибутивов) и для macOS как минимум необходимо использовать другой менеджер пакетов.

### Используемое ПО

Стандартный способ запуска демо-версии предполагает наличие установленного пакета *docker* (не ниже 25 версии), а также *docker compose* (входит в стандартный пакет Docker). Вручную выполняя соответствующие команды из файла Makefile в командной строке.

Другое используемое ПО (установка на Windows описана в следующем разделе):

- python (желательно версия не ниже 3.8)
- pipenv (для виртуальных окружений python, не ниже 3.8)
- pytest (фреймворк тестирования для валидации политик безопасности)

Для работы с кодом примера рекомендуется использовать VS Code или PyCharm.

В случае использования VS Code следует установить расширения

- REST client
- Docker
- Python
